# Glovo — онлайн платформа за поръчка и доставка на храна

Курсов проект по дисциплината „Софтуерно моделиране и анализ“.

## Автор

- Ивайло Джамбазов — факултетен №2401322010


## Описание

Проектът представя концептуален, логически и физически модел
на база данни за онлайн платформа за поръчка и доставка на храна.

Разработката включва релационна база данни, процедури, функции,
тригери, Data Warehouse модел и аналитичен доклад.
